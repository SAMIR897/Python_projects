# AES-256 Encryption Project
---
A 🔐 custom AES-256 encryption system with a 🖥️ multilayer GUI, built from scratch in 🐍 Python. Features 2-layer password security (4 passwords + dialpad lengths) and offline file/folder encryption.

## Features
---
- 🔧 Encrypt/decrypt files/folders with custom AES-256.
- 🛡️ 2-layer password system for secure access (no save option).
- 📋 Cross-platform file/folder selection (Mac, Linux, Windows).
- 🔐 Offline operation, transferable between machines.

## Installation
---
1. Clone: `git clone https://github.com/SAMIR897/Python_projects.git`
2. Navigate: `cd advance_projects/aes-encryption-project`
3. Run: `python src/main.py`

## Usage
---
- Set 4 passwords (e.g., save in notepad), then use dialpad (e.g., 2-3-5 presses + call).
- Select file/folder to encrypt (creates .enc file).
- Decrypt with same credentials on any machine.
